## Explanation

The purpose of this in-depth investigation is to investigate the performance of two distinct robotic systems, each of which was developed by a different student: Amir (myself) and Vahid. The purpose of this investigation is to simulate and operate a mobile robot in an environment that contains a number of golden boxes, with the objective of bringing all of the boxes together in a single location. The performance of my code is compared to that of Vahid's code, which is designed to achieve the same objective, and this report presents the results of the comparison. Through the execution of tests that altered the total amount of tokens present in the environment, the performance of two different implementations was evaluated. a measurement of their execution time for each task, as well as their success and failure rates, is taken into account.

It is the hypotheses that are presented in the next part that serve as the foundation for the performance evaluation. One of the most important metrics that is used to determine whether algorithm is superior is the amount of time that the robot needs to spend in order to collect all of the golden boxes in a single area. In addition, the study takes into account the number of times each algorithm has been successful and unsuccessful in locating and collecting the golden boxes. This is particularly important because the number of boxes in the environment can vary throughout the process.
