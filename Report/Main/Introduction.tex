\section{Introduction}\label{P1}
A comprehensive statistical analysis is carried out on the first assignment 
from Research Track 1 as part of the final work of Research Track 2. 
Simulating and directing a mobile robot in an area was the first task that must be completed 
for Research Track 1. It was expected that the robot would collect all of the golden boxes 
that were arranged close to each other in a single location inside the environment. 
Within the scope of this report, a comparison is made between the performance of my code 
and the performance of someone else's code that does the same task. 
Using the hypotheses that are discussed in the next section, 
the evaluation of performance is carried out. Both the amount of time it takes for 
the robot to collect all of the golden boxes that are adjacent to one another and 
the number of times that each algorithm is successful and unsuccessful in detecting and 
collecting the golden boxes when the number of boxes in the environment changes are 
the parameters that determine which algorithm performs better.
